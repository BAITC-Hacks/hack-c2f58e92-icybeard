## 2. Чего не хватает и что это ломает

| Пробел | Последствие | Обход без данных |
|---|---|---|
| История ИС БГ только за один квартал | Сезонность плановых направлений не выучить, временная валидация только внутри квартала | Ряды из списка пролеченных с 2012 года, но там нет очереди и отказов |
| Нет числа коек по организациям и профилям | Симулятор не может считать занятость; «что‑если по койкам» опирается на пропускную способность, а не на фонд | Оценка мощности через койко‑дни из списка пролеченных |
| Нет снимка текущей очереди | Демо показывает состояние I квартала 2025, а не сегодня; нельзя проверить прогноз проспективно | Честно указать как ограничение |
| Нет официального справочника МО с кодами, КАТО и координатами | Ставки соединяются только по названию, географии нет | Матчинг по названиям, координаты из data.egov.kz |
| Нет причин отказа в ИС БГ | Риск отказа предсказывается, но не объясняется причиной | Объяснение через профиль, организацию, диагноз |
| КДУ только за 2026, направления за 2025 | Поток диагностики не связывается с госпитализацией по периоду | Показать лаборатории отдельным потоком |
| Нет лабораторных данных ЕИП, хотя они заявлены в ТЗ | Подзадача «прогноз нагрузки на лаборатории» закрывается только выборкой КДУ | Запросить |
| Нет обезличенного идентификатора пациента между наборами | Нельзя построить путь пациента от диагностики до выписки | Агрегированный путь по региону и профилю |

## 4. Что берём из открытых источников сами

- Население по регионам и возрастам: Бюро национальной статистики, stat.gov.kz. Нужно для индекса на душу населения и знаменателей охвата вакцинацией.
- Медицинские организации с геопозициями: data.egov.kz, набор «Медицинские организации». Ключ только по названию, поэтому это резерв на случай, если официальный справочник не дадут.
- Границы регионов: открытые GeoJSON по КАТО для карты.
- Справочник МКБ‑10 на русском: для главы диагноза как признака и для подписей.
- Нормативные перечни ГОБМП и ОСМС: для экрана гражданина «что положено» из открытых НПА.
