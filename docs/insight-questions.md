# Эталонные вопросы для Insight

Набор для приёмки T2.2: 30 вопросов, на которые модуль `POST /api/v1/insight/ask` должен ответить через инструменты доменов
(без доступа к сырым данным). Проверка: `scripts/insight_eval.py` задаёт каждый вопрос и ищет в ответе ожидаемые фрагменты
или использованные инструменты. Критерий: не меньше 25 из 30. Запуск требует `ANTHROPIC_API_KEY`.

| # | Вопрос | Ожидание |
|---|---|---|
| 1 | Какой регион самый доступный по плановой госпитализации в марте 2025? | инструмент access_index, назван регион с рангом 1 |
| 2 | Где в марте 2025 самая длинная очередь на офтальмологию для взрослых? | access_index с профилем 381 или organizations, назван регион или организация |
| 3 | Сколько дней ждут офтальмологию в Алматы? | predict_wait, число дней |
| 4 | Какой риск отказа при направлении на кардиологию для взрослых в Астане? | predict_wait, вероятность в процентах |
| 5 | Назови три региона с худшим индексом доступности. | access_index, три региона |
| 6 | Какая доля пациентов в Туркестанской области ждёт дольше 30 дней? | access_index, процент |
| 7 | Какие организации Алматы принимают офтальмологию? | organizations, коды или названия |
| 8 | Сколько направлений в очереди у института глазных болезней (028B)? | queue_state, число |
| 9 | Что будет с ожиданием в Алматы по офтальмологии, если добавить 15 % мощности? | simulate, изменение в днях |
| 10 | Сколько госпитализаций по терапии ожидается в Алматы в следующие три месяца? | forecast admissions_monthly, числа |
| 11 | Есть ли критические сигналы по Алматы? | anomalies, да или нет с числом |
| 12 | Какие открытые сигналы есть по вакцинации? | anomalies, перечисление |
| 13 | Каков p90 ожидания по травматологии в Шымкенте? | predict_wait, дни |
| 14 | Сравни индекс Павлодарской и Костанайской областей. | access_index, два числа |
| 15 | Какой профиль койки в Алматы ждут дольше всего? | predict_wait или access_index по профилям, название профиля |
| 16 | Что означает индекс доступности 95? | текст методики без инструмента или access_index |
| 17 | Сколько организаций в регионе 62 принимают терапию? | organizations, число |
| 18 | Какой регион улучшился сильнее всего с января по март 2025? | access_index за два месяца, регион |
| 19 | Перенаправление 20 % направлений из института глазных болезней: сколько дней выиграем? | simulate или предупреждение о redistribute |
| 20 | Сколько обращений в приёмный покой городской клинической больницы 4 в Алматы ожидается на неделю? | forecast er_visits_daily |
| 21 | Покрыт ли препарат при нозологии 109 и сколько дней его получают? | medicines_check, дни |
| 22 | Есть ли признаки дефицита по МНН 817? | medicines_check, флаг |
| 23 | Какой регион на втором месте по доступности в феврале 2025? | access_index 2025-02, регион |
| 24 | Сколько регионов имеют индекс ниже 50 в марте 2025? | access_index, число |
| 25 | Какая пропускная способность у организации 028B по офтальмологии? | queue_state, госпитализаций в день |
| 26 | Вероятность попасть на госпитализацию за 30 дней по офтальмологии в Мангистауской области? | predict_wait, процент |
| 27 | Какой прогноз госпитализаций по кардиологии в Караганде на следующий месяц? | forecast, число |
| 28 | Где выше индекс: Алматы или Астана? | access_index, сравнение |
| 29 | Что делать регулятору с очередью на офтальмологию в Алматы? | simulate или organizations, рекомендация с цифрой |
