# Сценарий демонстрации (7 минут)

Живой стенд: https://dc.jurek.kz (вход Keycloak — «Войти» в шапке: `regulator1`, `doctor1`, `citizen1` … / `darumen`). Питч-дек: https://dc.jurek.kz/pitch.html (переключатель РУС/ҚАЗ справа сверху). Что есть на каждой странице: [demo-pages.md](demo-pages.md).

Подготовка локально: `make up` (весь стек в Docker) или по частям: `make serve`, `make publish`, `make models-serve`, `make scribe-serve`, `dotnet run --project src/Darumen.Api`, `cd apps/web && npm run dev`.

Цифры ниже сверены со стендом 13.09.2026 — после переобучения они могут сдвигаться на единицы; смысл шага от этого не меняется.

1. **Проблема (30 с).** Очереди на плановую госпитализацию: в Алматы по офтальмологии 1 784 направления в институте глазных болезней, медианное ожидание фактической очереди 47 дней, прогноз для нового направления ≈94 дня и 43 % риска отказа; рядом организации с ожиданием 6–7 дней.
2. **Карта регионов, роль regulator (60 с).** `/gov`: индекс доступности за март 2025 по регионам, 20 центров; пороги NHS (126 дн.) и CIHI (112 дн.) подписаны как внешний ориентир. Кнопки «Отчёт PDF / Excel» — месячный отчёт из тех же витрин. Лента сигналов: «Подтвердить» и «Ложный сигнал» — каждое решение уходит в журнал и становится меткой для дообучения детектора.
3. **Регион и организация (60 с).** `/gov/regions/75`: очередь института за 90 дней, факт p50/p90, прогноз по профилю с интервалом; плоские прогнозы честно подписаны «уровень последнего месяца» с сезонной формой NHS. Ссылка «кабинет организации» → `/gov/organizations/028B` — очередь, прогноз и сигналы одной организации.
4. **Симулятор (60 с).** `/gov/simulator`: +15 % мощности даёт −1.3 дня по группе; перераспределение до 20 % направлений даёт 2 390 дней ожидания меньше за 90 дней. Строка LOS: средняя длительность лечения ячейки → «одна койка ≈ 1/LOS госпитализаций в день» — так койки переводятся в пропускную способность. Ориентир коечного фонда Eurostat/ВОЗ подписан.
5. **Вопросы к данным (30 с).** `/gov/insight`: «Какой регион самый доступный в марте 2025?» → ответ с цифрой и графиком, список инструментов; на DeepSeek ответ за 3–13 с, 29 из 30 эталонных вопросов ([insight-questions.md](insight-questions.md)).
6. **Врач (90 с).** Роль doctor: `/doctor/referral` — прогноз ≈94 дня и 43 % отказа с объяснением факторов и строкой метрик модели; для организаций вне обучения риск словами («выше среднего»), не процентом. Альтернативы 6–7 дней, «Направить сюда» пишет решение в журнал (Idempotency-Key). `/doctor/worklist` — синтетические пациенты с флагами, клик ведёт в ассистент с заполненными параметрами. Маршрут пациента (`GET /api/v1/route/{patientRef}`, экраны — в работе): стадия по Стандарту, истёкшие 14-дневные анализы при ожидании 47 дней, риск отказа, «Направить сюда» с причиной → решение в журнале, а у гражданина на `/route/me` появляется «врач предложил другую организацию». `/doctor/scribe`: согласие, стенограмма, черновик по разделам (20/20 сценариев на двух языках), утверждение, памятка по ссылке, аудио удалено.
7. **Гражданин и лекарства (45 с).** `/wait` без входа: ≈80 дней по региону, где быстрее, сезонный ориентир листа ожидания (NHS, подписан «внешний ориентир»); `/medicines`: покрытие, сроки обеспечения (медиана 0 дней, p90 1 день), признак дефицита. Мобильное приложение: те же экраны, вход Keycloak.
8. **Стюард и данные (30 с).** `/steward`: 17 партий загрузки — события из Python через Schema Registry либо манифесты при публикации. `make intake-status` и карантин.
9. **Закрытие (30 с).** `/quality` — страница качества моделей: каждая модель против baseline (ожидание −17 % к ошибке, LOS −21 %, survival C-index 0.744 против 0.668 на новых организациях), доля плоских прогнозов 23,5 %, разметка сигналов людьми, ориентир WUENIC (охват DTP3 54 % против административной отчётности). Ограничения и 13 запросов данных — [status.md](status.md).
