# Сценарий демонстрации (7 минут)

Живой стенд: https://dc.jurek.kz (роль в шапке, без пароля). Что есть на каждой странице и что показывать: [demo-pages.md](demo-pages.md).

Подготовка локально: `make serve`, `make publish`, `make models-serve`, `make scribe-serve`, `dotnet run --project src/Darumen.Api`, `cd apps/web && npm run dev`. Роль переключается в шапке (демо-режим) или входом Keycloak (`regulator1` / `darumen`).

1. **Проблема (30 с).** Очереди на плановую госпитализацию: в Алматы по офтальмологии 1 784 направления в институте глазных болезней, медианное ожидание 55 дней, треть отказов; рядом организации с ожиданием 9 дней.
2. **Карта регионов, роль regulator (60 с).** `/gov`: индекс доступности за март 2025 по регионам, 20 центров регионов; клик в г. Алматы. Открытые сигналы аномалий сверху ленты.
3. **Регион и организация (60 с).** `/gov/regions/75`: очередь института за 90 дней, факт p50/p90, прогноз госпитализаций по профилю с интервалом; подтверждение сигнала уходит в журнал и в Kafka.
4. **Симулятор (60 с).** `/gov/simulator`: +15 % мощности даёт −1.3 дня по группе; перераспределение 20 % направлений даёт 2 390 дней ожидания меньше за 90 дней. Интервал по потоку ±20 %.
5. **Вопросы к данным (30 с).** `/gov/insight`: «Какой регион самый доступный в марте 2025?» → ответ с цифрой и графиком, список инструментов. Без ключа показать `docs/insight-questions.md`.
6. **Врач (90 с).** Роль doctor: `/doctor/referral` прогноз 101 день и 50 % отказа с объяснением, альтернативы 9 дней, «Направить сюда» пишет решение в журнал (Idempotency-Key). `/doctor/worklist` синтетические пациенты с флагами. `/doctor/scribe`: согласие, стенограмма (микрофон или текст), черновик по разделам, утверждение, памятка по ссылке, аудио удалено.
7. **Гражданин и лекарства (45 с).** `/wait` без входа: 80 дней по региону, где быстрее; `/medicines`: покрытие, сроки обеспечения (медиана 0 дней, p90 1 день), признак дефицита. Мобильное приложение: те же экраны.
8. **Стюард и данные (30 с).** `/steward`: партии загрузки пришли событиями из Python через Schema Registry. `make intake-status` и карантин.
9. **Закрытие (15 с).** Цифры из `make eval`, ограничения и запросы данных ([status.md](status.md)).
