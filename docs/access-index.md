# Индекс доступности плановой госпитализации

Считается ежемесячно по региону и профилю койки из фактических исходов направлений (только круглосуточные стационары).

1. Доля госпитализированных, ждавших дольше 30 дней, и 90-й перцентиль ожидания в днях.
2. Обе величины ранжируются по регионам внутри месяца и профиля (перцентильный ранг).
3. Индекс = 100 − среднее двух перцентильных рангов: 100 у самого доступного региона, 0 у наименее доступного.
4. Строки с числом госпитализаций меньше 5 подавляются (правило малых чисел). Профиль `all` объединяет все профили.

Ограничения: индекс относительный (сравнивает регионы между собой в один месяц), не абсолютный; на данных I квартала 2025 года он покрывает три месяца. При появлении истории за несколько лет добавится сравнение с тем же месяцем прошлого года.
